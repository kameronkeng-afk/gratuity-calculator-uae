## 🔨 STEP 1: APK Build Karna (Android Studio)

### Requirements
- Android Studio Hedgehog (2023.1.1) ya newer
- Java 11 ya higher
- Internet connection (dependencies download hogi)

### Steps
```
1. Android Studio open karein
2. "Open an Existing Project" → yeh GratuityUAE folder select karein
3. Gradle sync hone dein (internet chahiye)
4. Build → Generate Signed Bundle/APK click karein
5. "APK" select karein → Next
6. Keystore banayein (pehli dafa):
   - Key store path: koi bhi safe jagah
   - Password: strong password
   - Key alias: gratuityuae
   - Validity: 25+ years
7. Release build select karein → Finish
8. APK milegi: app/release/GratuityCalculatorUAE_v1.0.apk
```
